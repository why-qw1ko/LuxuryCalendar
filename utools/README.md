# Luxury日历 uTools 插件

从原日历项目移植，支持月、周、日视图、农历、节气、节假日调休、历史上的今天、日期差以及原有个性化设置。

## 构建与安装

在本目录执行：

```sh
npm install
npm test
npm run build
```

在 uTools 开发者工具中选择 `utools/dist/plugin.json` 接入插件；构建后整个 `dist` 目录是插件产物。在 uTools 中搜索「日历」「农历」或 `calendar` 进入。源码变更后需要重新执行构建并在开发者工具中重新加载插件。`npm run dev` 可用于普通浏览器预览页面，但不能替代 uTools 内测试。

插件退出到后台时释放页面资源，重新进入时显示当天。主题、时区及显示项保存在插件页面的 localStorage，与原网页的存储相互独立，不会自动迁移或同步。

农历、节气和节日名称使用 lunar-javascript，界面支持 1900–2100 年。节假日调休数据来自 [Hi8](https://hi8.com/t/jiejiari-api)，2027 年另有国务院公告的内置兜底；历史事件来自中文维基百科。网络或服务不可用时使用原项目的本地兜底，缺少调休数据的年份标注为「数据未覆盖」。外部请求只包含查询日期，不发送保存的设置。
